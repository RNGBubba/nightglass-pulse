# Nightglass Pulse

An original 20-second instrumental loop in D dorian at 120 BPM. The WAV is synthesized from scratch with Python's standard library; there are no samples, lyrics, covers, or borrowed melodies.

## Files

- `nightglass-pulse.wav`: stereo 44.1 kHz / 16-bit PCM loop.
- `generate_loop.py`: deterministic renderer.
- `BET.md`: offer, provenance, verification, and 30-day path.

## Regenerate

```sh
python generate_loop.py
```

The output is designed to repeat cleanly and is suitable as a short creator-video, podcast, stream, or prototype music bed. Suggested attribution: “Nightglass Pulse by RNGBubba.”
